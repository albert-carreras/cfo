# Windows XP artwork

The PNG icons in this folder, `start-logo.png`, the cursors in `cursors/` and the title bar
buttons in `window/` are Microsoft's Windows XP artwork, resized for
this app's skin. They are not covered by this repository's MIT license. Taken from the npm
packages `ngx-xp-icons` (icons) and `@caoergou/windows-xp` (the Start button flag, the cursors
and the title bar buttons).
